## 直播长连接数据采集：(c#)

大幅度修改弹幕解码器DouyinBarrageGrab
让他更好的担任解码器的功能。
第一是完整的输出原始流。纯粹的二进制编码，未经解码的原始流保留最完整的信息
第二是完整的解码，以最新的官方的前端 js来做完整的解码。这个解码出来的东西非常的大，只是个临时文件，这个时候就交给下游的分析器来做蒸馏和分析了，包括所有礼物的去重分组都是在下游应用进行的，这样权职分配更合理。
而且整个开发链路就很顺滑，本项目就只负责解码，所有的筛选和适配都是放到分析器的第一层raw层里面，通过蒸馏映射表来做筛选。

当然对老格式的所有能力做了保留，并且还增加了一个ws直接落盘的功能。
具有本地解码能力，对本地的流也能实现多线程快速回放。
优化代理能力，对网络的阻塞更小。

## 评论区舆情审核：（py）

定时采集博主最近一段时间或最近若干视频的评论区(动态限制防风控且保留命中率，避免死磕巨型视频)，按视频分文件保存评论数据，自动去重，支持一级评论和二级评论。

提供三种扫描模式：极速扫描、逻辑扫描、全面扫描。
极速扫描只扫描若干页数，具体动态的参考评论增长的数量；
逻辑扫描在重复度达到阈值后停止；
全面扫描则完整遍历全部评论。

基于抖音评论排序特点（前期热评权重高，后期偏时间排序），通过三种模式实现更低延迟、更快发现舆情。

审核器读取评论文件，根据评论关键词、用户关键词、子评论数量阈值进行命中检测，命中后通过邮件提醒，并记录已处理状态，避免重复提醒。同时接入 LLM 进行恶意内容和带节奏行为的精确判断。

可用于评论区关键词监控、异常讨论提醒、高回复评论提示和基础舆情值守。
