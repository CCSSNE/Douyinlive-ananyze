**但是我可以做一个挑战，就是做成事件触发的流式分析器，一旦有新的事件，马上进入数据库进行分析和增量的变更，不要每次全量计算，这样就可以秒级实时刷新。同样，展示器方面，现在依托 s3云盘的数据注入型静态网页，也要做真正的前端后端分离的动态网页才能实时展示**
